## 3. エントリー異常系・制限

### 3-1. 入力バリデーション
- [ ] チーム名が空 → エラー表示され進めない
- [ ] 代表者名が空 → エラー表示され進めない
- [ ] 電話番号が空 → エラー表示
- [ ] 電話番号が不正形式（例: `abc`、`123`）→ 形式エラー表示
- [ ] 電話番号 `090-1234-5678` / `09012345678` → どちらも通る

### 3-2. 1ユーザー1年度1大会
- [ ] 同一ユーザーで、ある年度の大会にエントリー済みの状態で再度アプリを開く
- [ ] 大会選択画面上部に「◯◯年度は既にエントリー済み」の案内が出る
- [ ] その年度の大会は「エントリー済み年度」バッジ付きで選択不可
- [ ] 別年度の大会は引き続きエントリー可能
- [ ] （すり抜け確認）確定処理でも「既にエントリー済み」エラーになる

### 3-3. 受付期限（開催7日前まで）
- [ ] 開催まで **7日以上先** の大会 → 「受付中」で選択可
- [ ] 開催まで **6日以内 / 当日 / 過去** の大会 → 「**受付終了**」バッジ付きで選択不可、注記表示
- [ ] （境界）開催がちょうど7日後の大会 → 受付**可能**
- [ ] （境界）開催が6日後の大会 → 受付**不可**

### 3-4. 定員（capacity）
- [ ] 出場枠 = 申込数の大会 → 「満員」バッジ・選択不可
- [ ] 残り枠が2以下の大会 → 「残りN枠」バッジ表示
- [ ] 定員ちょうどで確定しようとすると「定員に達しています」エラー

## 4. 通知（LINE）

> `VITE_LIFF_ID` が本番（mockでない）ときのみ `/api/notify` が呼ばれる。

- [ ] エントリー確定後、**申込者本人**のLINEに受付控えメッセージが届く
- [ ] メッセージに大会名・年度・開催日・会場・チーム名・受付番号が含まれる
- [ ] `ADMIN_LINE_USER_ID` 設定時、**管理者本人**にも申込通知が届く
- [ ] `ADMIN_LINE_USER_ID` 未設定でも、申込者への通知・エントリー自体は成功する（エラーで止まらない）

---

## 5. 管理画面（/admin）

- [ ] `/admin` を通常ブラウザで開くとパスワード画面が出る
- [ ] 誤ったパスワード → 「パスワードが違います」
- [ ] 正しいパスワード（`VITE_ADMIN_PASSWORD`）→ 管理画面に入れる
- [ ] リロードしても認証が維持される（同一タブ内）

### 5-1. 大会管理
- [ ] 新規大会を作成 → 一覧に追加され、Supabase `tournaments` に反映
- [ ] 大会を編集（名称・開催日・会場・定員など）→ 反映される
- [ ] 公開/非公開を切替 → 非公開の大会はユーザー側「大会選択」に出ない
- [ ] 大会を削除 → 紐づくエントリーも消える（CASCADE）

### 5-2. エントリー一覧
- [ ] 大会を選ぶと、その大会のエントリー一覧が申込順に出る
- [ ] 各エントリーにチーム名・代表者名・**電話番号**が表示される
- [ ] キャンセル操作 → `status` が `cancelled` になり、一覧から外れる
- [ ] キャンセル後、その枠が空くので該当ユーザーは再エントリー可能になる

## 6. keep-alive（cron / 任意）

- [ ] `GET /api/keep-alive` に `Authorization: Bearer <CRON_SECRET>` 無しでアクセス → 401

- [ ] Vercel の cron 設定（毎日 1:00）が有効になっている
